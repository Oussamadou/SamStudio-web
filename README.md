## 🛠️ Deploying to Cloudflare Pages (Free - 60 Seconds)

1. **Option A: Direct GitHub Integration (Recommended)**
   - Push this workspace to your GitHub repository.
   - Log in to [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Workers & Pages** → **Create application** → **Pages**.
   - Select your GitHub repo, set Build Output Directory to `/`, and click **Save and Deploy**.

2. **Option B: Cloudflare Wrangler CLI (Direct Upload)**
   ```bash
   npx wrangler pages deploy ./ --project-name=samstudio
   ```
